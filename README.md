# Weather_time_series_KelompoK9_02
Proyek ini menganalisis tren dan pola cuaca menggunakan data historis Max Planck Institute. Analisis mencakup visualisasi suhu, kecepatan angin, kelembapan, defisit tekanan uap, radiasi matahari, serta tren menggunakan moving average dan model fitting.  Dataset: Kaggle – Weather Long-Term Time Series Forecasting
